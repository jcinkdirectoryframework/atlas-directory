Code Snippets

Here are the HTML structures for each layout pattern, including filter display attributes:

Standard Layout

Controls at the top, directory below. Radio + Checkboxes + Dropdown (moved).

<div data-atlas>
    <div id="occupation-filter-container"></div>

    <input data-search placeholder="Search...">

    <div data-filters
         data-filter-radio="status"
         data-filter-checkboxes="species,faction">
    </div>

    <div data-sort></div>
    <div data-chips></div>
    <div data-results></div>

    <button data-layout="grid">Grid</button>
    <button data-layout="list">List</button>

    <div data-directory>
        <article data-member>...</article>
    </div>
</div>

Slide-out Top Bar

Controls hidden in a collapsible top bar. Clean and mobile-friendly. Important: The entire page is wrapped in data-atlas.

Key Concept: data-atlas wraps everything — the top bar, the header, and the directory. This allows Atlas to discover controls wherever they are placed on the page. 
<div data-atlas>

    <!-- Fixed Top Bar (contains controls) -->
    <div class="topbar">
        <button class="topbar-toggle">☰ Controls</button>
        <div class="topbar-content">
            <div data-filters
                 data-filter-radio="status"
                 data-filter-checkboxes="species,faction">
            </div>
            <div data-sort></div>
            <div id="occupation-filter-container"></div>
            <input data-search placeholder="Search...">
            <div data-chips></div>
            <div data-results></div>
            <button data-layout="grid">Grid</button>
            <button data-layout="list">List</button>
        </div>
    </div>

    <!-- Page Header -->
    <div class="page-header">
        <h1>Our Members</h1>
    </div>

    <!-- Directory -->
    <div data-directory>
        <article data-member>...</article>
    </div>

</div>

Why this works: Atlas only looks for controls inside the data-atlas container. By wrapping the entire page, you can place controls anywhere — in the top bar, sidebar, footer, or alongside the directory.

Filter Display Attribute Summary:
  • data-filter-radio="status" — Radio buttons for the Status field
  • data-filter-checkboxes="species,faction" — Checkboxes for Species and Faction
  • data-filter-dropdown="occupation" — Dropdown for Occupation (moved via JavaScript)

Layout Tips

  • Controls are flexible — place them anywhere within data-atlas
  • Use CSS Grid or Flexbox for your own layout arrangements
  • Atlas provides layout classes — .atlas-layout-grid and .atlas-layout-list on the directory
  • Style member cards differently for grid vs list using these classes
  • For slide-out layouts, wrap the entire page in data-atlas so controls in the top bar are discovered
  • Use Filter Display Options to control how each filter appears
Tip: You can style the directory layout however you want. The atlas-layout-grid and atlas-layout-list classes are just starting points — override them with your own styles.
