Code Snippets

Here are the HTML structures for each layout pattern:

Example 1: Standard Layout

Controls at the top, directory below.

<div data-atlas>
    <input data-search placeholder="Search...">
    <div data-filters></div>
    <div data-sort></div>
    <div data-chips></div>
    <div data-results></div>
    <button data-layout="grid">Grid</button>
    <button data-layout="list">List</button>

    <div data-directory>
        <article data-member>...</article>
    </div>
</div>

Example 2: Sidebar Layout

Filters and controls in a sidebar, directory in the main area.

<div data-atlas style="display: flex; gap: 2rem;">
    <aside style="width: 250px;">
        <div data-filters></div>
        <div data-sort></div>
        <button data-layout="grid">Grid</button>
        <button data-layout="list">List</button>
    </aside>

    <main style="flex: 1;">
        <input data-search placeholder="Search...">
        <div data-chips></div>
        <div data-results></div>

        <div data-directory>
            <article data-member>...</article>
        </div>
    </main>
</div>

Example 3: Centered Minimal Layout

Clean, centered design with minimal controls.

<div data-atlas style="max-width: 800px; margin: 0 auto; text-align: center;">
    <h2>Our Members</h2>

    <input data-search placeholder="Search..." style="width: 100%;">

    <div style="display: flex; justify-content: center; gap: 1rem;">
        <div data-filters></div>
        <div data-sort></div>
    </div>

    <div data-chips></div>
    <div data-results></div>

    <div data-directory style="display: grid; grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); gap: 1rem; text-align: left;">
        <article data-member>...</article>
    </div>
</div>

Example 4: Two-Column Layout with Search Bar

Search bar spanning full width, filters and directory side by side.

<div data-atlas>
    <input data-search placeholder="Search..." style="width: 100%;">

    <div style="display: flex; gap: 2rem;">
        <div style="width: 300px;">
            <div data-filters></div>
            <div data-sort></div>
            <div data-chips></div>
        </div>

        <div style="flex: 1;">
            <div data-results></div>
            <button data-layout="grid">Grid</button>
            <button data-layout="list">List</button>

            <div data-directory>
                <article data-member>...</article>
            </div>
        </div>
    </div>
</div>

Example 5: Slide-out Top Bar

Controls hidden in a collapsible top bar. Clean and mobile-friendly.

<div data-atlas>
    <div class="topbar">
        <button class="topbar-toggle">☰ Controls</button>
        <div class="topbar-content">
            <div data-filters></div>
            <div data-sort></div>
            <input data-search placeholder="Search...">
            <div data-chips></div>
            <div data-results></div>
            <button data-layout="grid">Grid</button>
            <button data-layout="list">List</button>
        </div>
    </div>

    <div data-directory>
        <article data-member>...</article>
    </div>
</div>

Layout Tips

  • Controls are flexible — place them anywhere within data-atlas
  • Use CSS Grid or Flexbox for your own layout arrangements
  • Atlas provides layout classes — .atlas-layout-grid and .atlas-layout-list on the directory
  • Style member cards differently for grid vs list using these classes
Tip: You can style the directory layout however you want. The atlas-layout-grid and atlas-layout-list classes are just starting points — override them with your own styles.
