Atlas Documentation

A dependency-free, HTML-driven directory engine

Atlas transforms static HTML member lists into interactive directories with searching, filtering, sorting, and layout switching — all configured through semantic HTML.

Quick Start: Add data-atlas to your container, add controls with data-search, data-filters, and data-sort, then call new Atlas(). → Read the guide

Features

  • Zero Dependencies — No jQuery, no frameworks. Just vanilla JavaScript.
  • HTML-First — Configure everything through HTML attributes.
  • Instant Search — Type to filter members in real-time.
  • Faceted Filtering — Multi-select filters for any field.
  • Smart Sorting — Three-state toggle (asc → desc → off).
  • Layout Switching — Grid and list views with persistent preference.
  • No Flicker — Smooth loading with CSS transitions.
  • Accessible — Keyboard navigation, screen reader support.
  • ~1,000 Members — Optimised for directories of up to one thousand members.
