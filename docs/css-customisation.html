CSS Customisation

Style your Atlas directory

Atlas provides minimal core CSS for functionality. All visual styling is left to you. This gives you complete control over the look and feel of your directory.

What Atlas Provides

Atlas provides only these selectors:

SelectorPurpose
[data-atlas-loading] [data-directory]Hides directory during loading
[data-directory]Directory container
[data-directory].atlas-layout-gridGrid layout mode
[data-directory].atlas-layout-listList layout mode
[data-member][hidden]Hidden member
[data-member][data-hidden]Hidden member

Atlas CSS Reference

Atlas provides a small set of CSS classes that are applied to elements during runtime. You can use these classes to style Atlas-generated elements.

Layout Classes

ClassApplied ToDescription
.atlas-layout-grid[data-directory]Applied when grid layout is active
.atlas-layout-list[data-directory]Applied when list layout is active

Chip Classes

ClassApplied ToDescription
.atlas-chip[data-chips] childrenEach individual filter chip
.atlas-chip-removeButton inside .atlas-chipThe × button to remove a chip
.atlas-chip-textSpan inside .atlas-chipThe text label of the chip
.atlas-chips-emptySpan inside [data-chips]Displayed when no chips are active

Button Classes

ClassApplied ToDescription
.atlas-clear-allButton inside [data-chips]Clears all active filters

Counter Classes

ClassApplied ToDescription
.atlas-result-counterSpan inside [data-results]Displays "Showing X of Y members"

Filter Classes

ClassApplied ToDescription
.activeFilter buttons ([data-filter-options] button)Applied when a filter value is selected

Sort Classes

ClassApplied ToDescription
.activeSort buttons ([data-sort] button)Applied to the currently active sort field
.ascSort buttons ([data-sort] button)Applied when sorting ascending (↑)
.descSort buttons ([data-sort] button)Applied when sorting descending (↓)

Visibility Classes

Class/AttributeApplied ToDescription
[hidden]Individual [data-member]Applied when a member is hidden by filters/search
[data-hidden]Individual [data-member]Alternate attribute for hidden members
Tip: You can override any of these classes in your own CSS. Atlas uses minimal specificity, so your styles will take precedence.

What You Should Style

ElementSuggested Styling
[data-search]Input field styling
[data-filters]Container layout, spacing
[data-filter]Filter group layout
[data-filter-options] buttonFilter buttons (active/inactive states)
[data-sort] buttonSort buttons (active/asc/desc states)
[data-chips]Chip container
.atlas-chipIndividual chip
.atlas-chip-removeRemove button on chip
.atlas-clear-allClear All button
.atlas-result-counterResult counter text
[data-layout]Layout toggle buttons
[data-member]Member card styling
[data-field]Individual field display

Example CSS

Here's a complete example of custom styles you might add to your site:

/* ─── Search Input ────────────────────────────────── */

[data-search] {
    padding: 0.5rem 1rem;
    font-size: 1rem;
    border: 1px solid #ccc;
    border-radius: 4px;
    width: 100%;
    max-width: 300px;
    transition: border-color 0.2s;
}

[data-search]:focus {
    outline: none;
    border-color: #2563eb;
    box-shadow: 0 0 0 3px rgba(37, 99, 235, 0.2);
}

/* ─── Filter Buttons ───────────────────────────────── */

    flex-wrap: wrap;
    gap: 0.25rem;

}

[data-filter-options] button.active {

    color: white;
    border-color: #2563eb;
}

/* ─── Sort Buttons ─────────────────────────────────── */

    display: inline;
}

Tips

  • Use CSS variables for theming — makes global changes easier
  • Start with the demo.css in the repository as a reference
  • Test both grid and list layouts when customising member cards
  • Don't override !important unless necessary — Atlas uses minimal specificity
