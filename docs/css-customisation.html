CSS Customisation

Style your Atlas directory

Atlas provides minimal core CSS for functionality. All visual styling is left to you. This gives you complete control over the look and feel of your directory.

What Atlas Provides

Atlas provides only these selectors:

SelectorPurpose
[data-atlas-loading] [data-directory]Hides directory during loading
[data-directory]Directory container
[data-directory].atlas-layout-gridGrid layout mode
[data-directory].atlas-layout-listList layout mode
[data-member][hidden]Hidden member
[data-member][data-hidden]Hidden member

Atlas CSS Reference

Atlas provides a small set of CSS classes that are applied to elements during runtime. You can use these classes to style Atlas-generated elements.

Layout Classes

ClassApplied ToDescription
.atlas-layout-grid[data-directory]Applied when grid layout is active
.atlas-layout-list[data-directory]Applied when list layout is active

Chip Classes

ClassApplied ToDescription
.atlas-chip[data-chips] childrenEach individual filter chip
.atlas-chip-removeButton inside .atlas-chipThe × button to remove a chip
.atlas-chip-textSpan inside .atlas-chipThe text label of the chip
.atlas-chips-emptySpan inside [data-chips]Displayed when no chips are active

Button Classes

ClassApplied ToDescription
.atlas-clear-allButton inside [data-chips]Clears all active filters

Counter Classes

ClassApplied ToDescription
.atlas-result-counterSpan inside [data-results]Displays "Showing X of Y members"

Filter Classes

ClassApplied ToDescription
.activeFilter buttons ([data-filter-options] button)Applied when a filter value is selected

Sort Classes

ClassApplied ToDescription
.activeSort buttons ([data-sort] button)Applied to the currently active sort field
.ascSort buttons ([data-sort] button)Applied when sorting ascending (↑)
.descSort buttons ([data-sort] button)Applied when sorting descending (↓)

Visibility Classes

Class/AttributeApplied ToDescription
[hidden]Individual [data-member]Applied when a member is hidden by filters/search
[data-hidden]Individual [data-member]Alternate attribute for hidden members
Tip: You can override any of these classes in your own CSS. Atlas uses minimal specificity, so your styles will take precedence.

Customising Filter Order

By default, Atlas displays filters in the order they are discovered in your member data. You can reorder them or move a specific filter to a different location using CSS or a simple script.

Tip: These techniques work with any filter — just replace faceclaim with your field name.

Option 1: Reorder Filters with CSS (Simple)

Use CSS order to visually reorder filters without changing your member data. 

/* Move a filter to the top */
[data-filter][data-field="faceclaim"] {
    order: -1;
}

/* Move a filter to the bottom */
[data-filter][data-field="status"] {
    order: 999;
}

How it works: The data-filter container has a data-field attribute matching your field name. CSS order repositions it within the flex container.

Note: This only works if [data-filters] uses display: flex. If you've changed it to grid, you may need to use grid-row or grid-column instead.

Option 2: Move a Filter to a Different Location

If you want a specific filter to appear in a different part of your page (like a sidebar or above the search bar), you can move it using a small script.

Step 1: Add a target container where you want the filter to appear.

<div id="faceclaim-filter-container"></div>

Step 2: Add this script after initialising Atlas.

<script type="module">
    import Atlas from 'https://atlas-directory.netlify.app/atlas.min.js';

    new Atlas();

    // Wait for Atlas to generate the filters
    requestAnimationFrame(() => {
        const faceclaimFilter = document.querySelector('[data-filter][data-field="faceclaim"]');
        const targetContainer = document.getElementById('faceclaim-filter-container');
        if (faceclaimFilter && targetContainer) {
            // Move it to the new location
            targetContainer.appendChild(faceclaimFilter);
        }
    });
</script>

How it works: Atlas generates the filters, then the script finds the faceclaim filter and moves it to your designated container.

Tip: Replace faceclaim with your own field name, and faceclaim-filter-container with the ID of your target container.

Quick Reference

Goal Method Code
Move filter to the top of the list CSS [data-filter][data-field="FIELDNAME"] { order: -1; }
Move filter to the bottom of the list CSS [data-filter][data-field="FIELDNAME"] { order: 999; }
Move filter to a different location on the page JavaScript See Option 2 above

Tips

  • Use CSS variables for theming — makes global changes easier
  • Test both grid and list layouts when customising member cards
  • Don't override !important unless necessary — Atlas uses minimal specificity
  • For mobile, ensure your tap targets are at least 44px
  • Adding CSS to JCink: Add custom styles to your forum's global CSS, or add a <style> block in your Member List Header.
