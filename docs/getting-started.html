Getting Started

Add Atlas to your site in three steps

Atlas is designed to be as simple as possible. You configure it through HTML, style it with CSS, and initialise it with a single line of JavaScript.

Quick Start: Use the CDN links below — no files to download or upload! → JCink users, see the full guide

CDN Installation (Recommended)

The quickest way to get started — no files to upload!

<!-- CSS -->
<link rel="stylesheet" href="https://atlas-directory.netlify.app/atlas.min.css">

<!-- JavaScript -->
<script type="module">
    import Atlas from 'https://atlas-directory.netlify.app/atlas.min.js';
    new Atlas();
</script>
Tip: That's it! No files to download or upload. See the JCink Installation Guide for JCink-specific instructions.

Step 1: Add HTML

Add the data-atlas attribute to your container, then add controls and members.

<div data-atlas>
    <!-- Search -->
    <input data-search placeholder="Search members...">

    <!-- Controls -->
    <div data-filters></div>
    <div data-sort></div>
    <div data-chips></div>
    <div data-results></div>

    <!-- Layout buttons (optional) -->
    <button data-layout="grid">Grid</button>
    <button data-layout="list">List</button>

    <!-- Members -->
    <div data-directory>
        <article data-member>
            <div><strong>Name:</strong> <span data-field="name" data-searchable="true" data-sortable="true" data-filterable="false">Din Djarin</span></div>
            <div><strong>Faceclaim:</strong> <span data-field="faceclaim" data-searchable="true" data-sortable="true" data-filterable="false">Pedro Pascal</span></div>
            <div><strong>Species:</strong> <span data-field="species" data-sortable="true">Human</span></div>
            <div><strong>Occupation:</strong> <span data-field="occupation" data-searchable="true" data-sortable="true">Bounty Hunter</span></div>
            <div><strong>Faction:</strong> <span data-field="faction" data-sortable="true">Mandalorian</span></div>
            <div><strong>Homeworld:</strong> <span data-field="homeworld" data-sortable="true">Aq Vetina</span></div>
            <div><strong>Status:</strong> <span data-field="status" data-sortable="true">Active</span></div>
        </article>
        <!-- Add more members -->
    </div>
</div>
Tip: Controls can be placed anywhere within data-atlas. Atlas discovers them automatically.

Step 2: Add CSS

Atlas provides minimal core CSS. You can customise everything else.

Option A: CDN (Recommended)

<link rel="stylesheet" href="https://atlas-directory.netlify.app/atlas.min.css">

Option B: Self-Host

<link rel="stylesheet" href="path/to/atlas.css">

Or copy the contents of src/styles/atlas.css into your own stylesheet. See CSS Customisation for styling guidance.

Step 3: Add JavaScript

Option A: CDN (Recommended)

<script type="module">
    import Atlas from 'https://atlas-directory.netlify.app/atlas.min.js';
    new Atlas();
</script>

Option B: Self-Host

<script type="module">
    import Atlas from './dist/atlas.js';
    new Atlas();
</script>

That's it! Atlas discovers everything automatically.

Performance Tips

  • Lazy rendering — Activates automatically when a directory has more than 300 members. Only visible members are rendered in the DOM.
  • Filter caching — Filter results are cached. Applying the same filter twice is instant.
  • Set lookups — Filter values use Set for O(1) lookups, making filtering fast even with 1,000+ members.
Performance Tip: Atlas automatically handles performance for you. For directories with more than 300 members, lazy rendering activates automatically. You don't need to configure anything.

Accessibility

  • Keyboard navigation — All controls are accessible via keyboard (Tab, Enter, Space).
  • Screen readers — ARIA labels and roles are built in.
  • Reduced motion — Respects prefers-reduced-motion system setting.

Mobile Optimisation

  • Touch targets — All interactive elements have a minimum tap target of 44px.
  • Responsive grid — Grid columns adjust automatically on smaller screens.
  • iOS zoom prevention — Search inputs use 16px font size to prevent iOS zoom.
